Sistema: Coach Play
1. Objetivo da aplicação

Criar uma aplicação chamada Coach Play, uma plataforma de análise de partidas de EA FC para jogadores de Xbox, com foco em identificar erros, padrões de jogo e oportunidades de melhoria.

A aplicação deverá permitir que o usuário envie ou capture partidas, receba análise da IA e acompanhe sua evolução como jogador.

Dor principal

O jogador sabe que está perdendo, errando passes, sofrendo gols ou tomando contra-ataques, mas não consegue identificar claramente quais erros está cometendo.

O Coach Play resolve isso funcionando como um treinador digital, analisando a partida e explicando os erros de forma simples.

Público-alvo
Jogadores casuais de EA FC.
Jogadores competitivos.
Usuários de Xbox.
Pessoas que querem melhorar no jogo.
Criadores de conteúdo gamer.
Pequenos times ou comunidades de eSports.
2. Domínio principal

O domínio principal é:

Análise inteligente de desempenho em partidas de futebol digital.

Em linguagem simples:

O sistema assiste à partida do jogador, identifica comportamentos ruins, mostra onde ele errou e sugere como melhorar.

Problemas reais do domínio
O jogador não sabe por que perdeu.
O jogador repete os mesmos erros sem perceber.
O jogador não sabe se o problema é ataque, defesa, passe, marcação ou tomada de decisão.
Durante a partida, o jogador não consegue analisar tudo.
Depois do jogo, o jogador esquece os lances importantes.
Não existe um “técnico particular” acessível para jogadores comuns.

9. Regras de negócio
Regra	Descrição	Erro
E-mail único	Não pode existir mais de uma conta com o mesmo e-mail	Este e-mail já está cadastrado
Usuário inativo	Usuário inativo não pode acessar	Seu acesso está bloqueado
Vídeo obrigatório	Toda análise precisa de um vídeo válido	Envie um vídeo da partida
Formato válido	Aceitar apenas formatos permitidos	Formato de vídeo não suportado
Limite do plano	Usuário não pode analisar acima do limite	Seu limite de análises acabou
Análise em processamento	Não permitir duplicar análise da mesma partida	Esta partida já está sendo analisada
IA indisponível	Usar API reserva em caso de falha	Estamos tentando outro serviço de IA
Dados sensíveis	Nunca expor chave de API no frontend	Acesso negado
Relatório privado	Jogador só vê suas próprias partidas	Você não tem permissão para acessar este relatório

Prompt base da IA Coach
Você é um treinador especialista em EA FC.

Analise os eventos detectados da partida e explique para o jogador:
1. Quais foram os principais erros.
2. Em que momento aconteceram.
3. Qual categoria do erro: defesa, ataque, passe, finalização, tomada de decisão ou posicionamento.
4. Por que esse erro prejudicou o jogador.
5. Como ele pode corrigir isso na próxima partida.

Use linguagem simples, direta e motivadora.
Evite termos técnicos complexos.
Não invente dados que não foram detectados.
Se a análise for incerta, informe que é uma hipótese.
Controle de custo
Limitar minutos por plano.
Processar vídeo em trechos.
Analisar apenas momentos relevantes.
Salvar resultado para não reprocessar.
Registrar consumo por análise.
Usar IA mais barata para resumo simples.
Usar IA mais avançada apenas em lances críticos.
Fallback de IA
1. API principal de IA multimodal
2. API secundária
3. API reserva

- registrar erro
- tentar próxima

Crie a aplicação Coach Play.

Coach Play é uma plataforma SaaS para análise de partidas de EA FC, inicialmente para jogadores de Xbox. O objetivo é permitir que o usuário envie vídeos das partidas e receba uma análise feita por IA, identificando erros, padrões de jogo, pontos fortes e sugestões de melhoria.

Siga arquitetura modular, Clean Architecture e Domain-Driven Design.

Stack:
- Frontend: Next.js, TypeScript, Tailwind CSS, Shadcn/UI
- Backend: NestJS, TypeScript

- Infraestrutura: Docker
- Autenticação: JWT com refresh token seguro
- Upload de vídeo: armazenamento local inicialmente, preparado para S3
- IA: integração desacoplada com provider configurável
